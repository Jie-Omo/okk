# OKK Proxy Manager

## Proxy manager

```bash
wget -O vless-server.sh https://raw.githubusercontent.com/Jie-Omo/okk/master/vless-server.sh && chmod +x vless-server.sh && bash vless-server.sh
```

## nftables utility

```bash
curl -fsSL https://raw.githubusercontent.com/Jie-Omo/okk/master/nft.sh -o nft.sh && chmod +x nft.sh && ./nft.sh
```
